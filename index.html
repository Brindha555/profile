Docker

Packages an application with its libraries into a container, so it runs the same on my laptop, a teammate's machine or a server.

Useful for Flask apps that depend on specific Python packages.

Jenkins

Automates repetitive steps. When code changes, Jenkins can build the project and run tests, so mistakes show up early.

LangChain

A framework for connecting language models to prompts, data sources and tools, so an AI feature can be built as a chain of clear steps.

LangGraph

Extends that idea to workflows with branches and loops, where an AI agent decides the next step and can retry or hand off.

RAG

Retrieval-augmented generation. The model looks up relevant documents first and answers from them, which keeps replies grounded in real information.

Prompt engineering

Writing clear instructions, context and examples so a model gives consistent, useful output.
